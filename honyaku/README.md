# Honyaku Portable

Windows 向けの常駐翻訳ツールです。Go 標準ライブラリと Win32 API のみを使い、外部 DLL やインストーラーなしの単一 exe にビルドします。翻訳には DeepL API を使います。

## ビルド

Go 1.22 以降を用意して、このフォルダーで実行します。

```powershell
go build -trimpath -ldflags="-s -w -H=windowsgui" -o Honyaku-v1.0.1.exe .
```

`Honyaku-v1.0.1.exe` を任意のフォルダーに置いて起動してください。初回起動時に同じ場所へ `config.json` が作成されます。設定メニューからファイルを開き、API キーを入力して保存し、「設定を再読み込み」を選択します。

```json
{
  "api": "deepl",
  "api_key": "ここにDeepL APIキー",
  "hotkey": "Ctrl+Shift+Q",
  "source_lang": "JA",
  "target_lang": "EN"
}
```

ホットキーの修飾キーは `Ctrl`、`Shift`、`Alt`、`Win`、主キーは英字・数字・`F1`〜`F24` に対応します。ほかのアプリが同じキーを登録済みの場合はホットキーを取得できません。

## 使い方

- トレイアイコンを右クリックして設定、設定再読み込み、Windows 起動時の実行切り替え、終了を選びます。
- 設定したホットキーを押し、入力欄に文章を入れて Enter を押します。
- ホットキーを押すと入力欄へフォーカスし、日本語 IME を有効にします。
- 成功すると訳文をクリップボードへコピーして入力欄を閉じます。Esc で翻訳をキャンセルしてすぐ閉じます。

API キーは `config.json` に平文で保存されます。Windows のレジストリ自動起動は HKCU の Run キーを使います。
アプリは多重起動を防ぎます。初期化や翻訳に問題が起きた場合は、exe と同じフォルダーの `Honyaku.log` にエラーが追記されます。ショートカットキーが別アプリと競合している場合も記録されるため、`config.json` で別のキーに変更してください。

## フルスクリーンについて

ポップアップは Win32 の topmost ウィンドウとして表示し、表示中は 250ms ごとに最前面の z-order を再適用します。前面化と入力欄へのフォーカスも要求します。ただし Direct3D の排他的フルスクリーンではゲームが画面出力を占有するため、通常のデスクトップウィンドウを上に描画できない場合があります。Windows はフォーカス奪取も制限しており、アンチチートや管理者権限の異なるプロセスでも制約されます。確実に使うにはゲームをボーダレス表示にしてください。ホットキーは `RegisterHotKey` による通常のグローバルホットキーで、入力監視フックは使いません。

このアプリは OS に同梱の通知アイコン画像を使用します。単一 exe に Go ランタイムは含まれますが、Go ビルド時に必要な Windows 標準 DLL（user32、shell32、kernel32）を exe に静的埋め込みするものではありません。
